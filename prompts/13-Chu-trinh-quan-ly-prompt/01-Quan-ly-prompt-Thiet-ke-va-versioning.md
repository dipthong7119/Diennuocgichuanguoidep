# Prompt: Quản lý prompt bằng versioning và catalog

## Kỹ thuật minh họa
Prompt Management Cycle: Design, Testing & Evaluation, Refinement, Versioning & Cataloging, Deployment, Monitoring & Iteration.

## Prompt sử dụng

[Instructions]
Thiết kế quy trình quản lý prompt cho chức năng chatbot tư vấn sản phẩm trong hệ thống quản lý bán hàng.

[Context]
- Prompt chatbot cần tư vấn dựa trên dữ liệu sản phẩm còn hàng.
- Cần tránh tư vấn sản phẩm hết hàng hoặc bịa thông tin.
- Nhóm sinh viên cần lưu prompt trong repository để làm minh chứng sử dụng AI.

[Tasks]
1. Đề xuất cấu trúc thư mục lưu prompt.
2. Đề xuất metadata cho mỗi prompt.
3. Mô tả quy trình 6 giai đoạn quản lý prompt.
4. Đề xuất cách đặt version: v1.0, v1.1, v2.0.
5. Đề xuất checklist trước khi đưa prompt vào ứng dụng.

[Output Format]
Markdown gồm:
- Cấu trúc thư mục.
- Bảng metadata.
- Quy trình 6 giai đoạn.
- Checklist triển khai.
- Ví dụ changelog cho prompt chatbot.

---

## Yêu cầu ghi kết quả

Khi thực hiện prompt này, hãy ghi toàn bộ kết quả đầu ra vào một file Markdown mới trong cùng thư mục với file prompt.

Tên file kết quả phải giữ nguyên tên file prompt hiện tại và thêm hậu tố `_ket_qua` trước phần mở rộng `.md`.

Ví dụ: nếu file prompt là `01-Vi-du-prompt.md` thì file kết quả phải là `01-Vi-du-prompt_ket_qua.md`.
